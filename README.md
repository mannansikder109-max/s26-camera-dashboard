# S26 Ultra 200MP Camera Tech Dashboard

An interactive technical dashboard for understanding high-resolution smartphone imaging.

## Features

- Responsive mobile and desktop layout
- Mobile hamburger navigation
- 200MP sensor architecture section
- Interactive native, 4-in-1, and 16-in-1 pixel-binning simulator
- Effective pixel-size and output readouts
- OIS and multi-directional PDAF explanations
- Camera2 API, RAW capture, and manual-control guide
- Interactive image-data pipeline
- Pipeline explanation dialog
- Changelog section
- Static Vercel deployment ready

## Project Files

- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `app.js` — interactions and dashboard logic
- `vercel.json` — Vercel configuration
- `README.md` — project documentation

## Local Preview

Open `index.html` in a modern browser.

## Deployment

This is a static HTML, CSS, and JavaScript project. It can be deployed through GitHub and Vercel without a build command.

## Important Note

This dashboard is an educational technical interface. Device-specific specifications should be confirmed through official Samsung documentation.
